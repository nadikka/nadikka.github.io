N0

La bifurcación

Por qué ComfyUI y no Midjourney. La decisión no es técnica: es sobre quién controla la salida.

Código abierto vs. código cerrado

concepto

Lo cerrado es una aplicación: pocos inputs, salidas preseteadas, la estética y la censura las decide la corporación. Lo abierto es una herramienta: muchos parámetros, código que la comunidad modifica, sin garantías — la responsabilidad es tuya.

«¿Vieron la caja negra de los aviones? Un código cerrado, corporativo es justamente eso. No se sabe con qué está entrenado.»

CLASE → M4C1

Aplicación vs. herramienta

concepto

La app promete la respuesta mágica en un solo cuadro de texto. La herramienta te obliga a decidir — y cada decisión es un parámetro visible.

«El Confi es una caja de herramientas. No es solamente una aplicación para generar imagen o video.»

CLASE → M4C5

Libertad con cautela

concepto

Un modelo abierto puede venir con la censura borrada. Eso no es ni utopía ni catástrofe: es responsabilidad transferida del proveedor al usuario.

«Ninguno es la prisión y ninguno es la panacea... el otro es el libre albedrío que hay que usar con cautela y responsabilidad.»

CLASE → M4C1

No es una inteligencia

concepto

Procesa datos e interpreta palabras como tokens. Corre offline una vez descargado: nada 'busca en internet' salvo la descarga inicial del modelo.

«Esto no es una inteligencia, es una herramienta que procesa datos e interpreta palabras como tokens, pero no tiene conciencia.»

CLASE → M4C1

Generar es conducir un caos

concepto

No hay magia: hay un universo de posibilidades y parámetros que lo reducen. Cada nivel de este bastón es un juego más de riendas.

«Generar imágenes o video con Machine Learning es muy parecido a tratar de conducir una especie de caos.»

«El modelo solo puede reproducir con lo que fue entrenado.»

N1

El taller alquilado: Colab

No hace falta GPU propia. Se alquila gratis por unas horas al día — sabiendo que la máquina nace vacía cada vez.

Qué es Colab

herramienta

Una máquina virtual de Google con GPU (T4, ~15 GB de video) que corre Python en celdas. Arranca 'en cero' cada sesión: todo se instala de nuevo. El orden de las celdas importa — instalar ComfyUI primero arma las carpetas donde después caen los modelos.

«Collab está todo el tiempo tratando de que no usemos Confi... pero le encontramos una vueltita.»

CLASE → M4C1

El runbook de instalación

receta

Correr las celdas EN ORDEN (instalar ComfyUI → nodos → modelos → túnel), reiniciar cuando el notebook lo pide (el restart borra los tildes verdes pero NO lo instalado), y abrir el túnel al final. Si un nodo aparece en rojo al cargar un workflow: Manager → Install Missing Custom Nodes → Restart.

errores rojos Solo importan los que tienen botón rojo de error real. Mucho texto rojo en Colab es inofensivo (falsos negativos).

El túnel

herramienta

La celda que corre indefinidamente es el portal entre la VM y tu navegador: expone el ComfyUI de Colab como una URL que abrís vos. Si se corta, la interfaz muere aunque la GPU siga viva. Cuidado: cuentas Google corporativas bloquean Colab, y las cookies de terceros pueden romper el túnel.

Los límites del plan gratis

concepto

Aprox. 4 horas de GPU por día por cuenta; los créditos vuelven a las 24 hs (o se cambia de cuenta). El cuello de botella real no es la VRAM sino la RAM del sistema (~12 GB): por eso los workflows de clase 'flushean' la RAM entre corridas y ControlNet recalcula su mapa cada vez.

«El cuello de botella del gratuito es la RAM del sistema, no la GPU.»

CLASE → M4C5

Cuándo (y qué) pagar

decisión

Colab Pro (~10 USD / 100 créditos) da una A100 (40 GB GPU / 83 GB RAM, ~5 créditos por hora) — para workflows pesados o video largo. Alternativas nombradas en clase: RunPod, Paperspace, RunningHub (ComfyUI por créditos). Para ENTRENAR un LoRA casi siempre conviene alquilar afuera.

HALLAZGO → Nuestro training de LoRA para Z-Image Turbo se planificó afuera de la T4 (fal.ai / RunPod + AI Toolkit): la T4 alcanza para generar, no para entrenar un DiT de 6B.

advertencia

La rutina de rescate (memoria / inference fail)

receta

Cuando aparece 'model inference fail' o un pico de RAM tumba algo: (1) refrescar la página y reintentar; (2) si sigue: parar la celda del túnel, esperar que frene, volver a correrla, esperar 'reconnecting' → verde → refrescar la interfaz. Es la rutina que el docente repite en vivo — no es tu culpa, es la T4 gratuita al límite.

Cerrar sesión sin perder nada

receta

Antes de desconectar: parar el túnel → empaquetar la carpeta output en un zip → descargarlo (o mandarlo a Drive) → VERIFICAR que bajó → recién ahí 'desconectar y eliminar el entorno'. La VM se evapora con todo lo que no bajaste.

N2

El núcleo que no cambia

Ocho nodos. Todo modelo de difusión — Z-Image, SDXL, Flux, hasta el de video — pasa por esta misma columna vertebral.

El grafo mínimo

receta

Cargar modelo de difusión + cargar CLIP + cargar VAE + prompt positivo + prompt negativo + lienzo latente vacío → K-Sampler → VAE Decode → Save Image. En el workflow de la diplo es el grupo 'generacion'. Esta formulación la cerró un alumno en la última clase y el docente la validó: hay una unidad mínima a la que solo le cambiás entradas.

«Exacto, justo lo que estás diciendo.»

CLASE → M4C5

El modelo de difusión (checkpoint)

nodo

Los pesos: un archivo que bajás, guardás y corrés offline. El de la cursada es Z-Image Turbo (chino, fotorrealista, rápido, CFG clavado en 1, 8–15 steps). Un modelo es 'como un archivo comprimido con todas las posibilidades de representación' — y solo contiene lo que le entrenaron.

«Generar una imagen sería como trazar una línea en esa nube multidimensional.»

CLASE → M4C2
weight_dtype fp8_e4m3fn para Z-Image Turbo en la T4 — precisión recortada para que entre en 15 GB.

CLIP: palabras → tokens

nodo

Traduce el prompt a vectores que el modelo entiende. Z-Image usa Qwen3-4B como encoder (cargado aparte); Flux necesita DOS encoders (DualClipLoader); SDXL lo trae adentro del checkpoint. Prompt en inglés (DeepL si hace falta), el ORDEN de las palabras influye, y lo que no especificás queda librado al azar del entrenamiento.

«La mayoría de los errores dentro de una generación tienen que ver con los prompts... el modelo lo va a dejar librado al azar.»

CLASE → M4C2

VAE: el revelado

nodo

El K-Sampler trabaja en un espacio comprimido ('como adentro de un zip'). El VAE Decode vuelve visible esa imagen latente; el VAE Encode hace el camino inverso (meter una foto al latente, para img2img). La analogía de clase es fotográfica: la latente es el negativo, el VAE es el revelado.

«¿Se acuerdan cuando cargábamos un negativo? La imagen existía en el negativo como una imagen latente.»

CLASE → M4C1

El lienzo latente

nodo

Empty Latent Image define ancho×alto (en clase: 1024×640; invertir los valores rota la orientación). Es el casillero intercambiable del grafo: en img2img se bypassea y entra una imagen codificada; en video, entran frames.

K-Sampler: la coctelera

nodo

Junta modelo, prompt positivo, negativo y latente, y ejecuta la difusión. Acá viven casi todos los parámetros que importan.

seed fixed = misma imagen reproducible; randomize = variaciones. 'Algo tiene que cambiar' para que cambie el resultado.
steps Turbo: 8–15. Más steps no es más calidad: hay un punto de corrupción.
CFG Cuánto obedece al prompt. En Z-Image Turbo va clavado en 1 — no tocarlo salvo experimento. Base/Flux usan valores más altos.
sampler / scheduler Hay un montón; los workflows de la comunidad ya vienen calibrados. No es la primera perilla a tocar.
denoise LA perilla maestra: 0 = respeta la entrada, 1 = obedece solo al prompt. Reaparece en img2img, tile y video.

Cada modelo, su workflow

concepto

SDXL trae modelo+CLIP+VAE en un solo checkpoint (nodo Load Checkpoint y listo). Z-Image carga las tres piezas por separado. Flux pide dos encoders. El workflow base lo publica quien saca el modelo; la comunidad deriva variantes mejoradas. Moraleja de clase: no corras atrás del último modelo — SD1.5 corre hasta en un iPhone y SDXL con buenos workflows sigue sacando cosas increíbles.

«Hay que tratar de romper un poco esa idea de que todo en inteligencia artificial es automático y rápido.»

CLASE → M4C5

Cuantización: GGUF y FP8

concepto

Versión 'afeitada' de un modelo: menos precisión = menos VRAM = corre en placas chicas, con algo de degradación. Se elige según la GPU (Q4 ≈ 5 GB, Q8 ≈ 8 GB; LTX en FP16 pesa 42 GB, en FP8 23 GB).

HALLAZGO → El workflow de la diplo usa Z-Image Turbo en GGUF Q5_K_M — el punto medio calidad/peso para la T4.

N3

Doblar la salida: control

Cinco maneras de que la imagen haga lo que vos querés — y cuál usar para qué.

¿Qué quiero controlar?

decisión

Identidad o estilo recurrente → LoRA. Composición, pose o estructura → ControlNet. Partir de una imagen existente → img2img. Describir, editar o combinar por lenguaje → Qwen VLM. Detalle y resolución → Tile/upscale. La regla de reparto es del docente:

«Con Control Net y el mapa de profundidad armás la composición, y con el prompt le das la textura.»

CLASE → M4C3

img2img: partir de una imagen

receta

Bypass al lienzo vacío; entra Load Image → VAE Encode → al latent_image del K-Sampler. El denoise regula el tira y afloje: cerca de 0 se parece a tu imagen, cerca de 1 obedece al prompt. En texto-a-imagen le decís TODO al modelo; en img2img ya partís de direcciones que la imagen trae.

«Eso que falta de información no lo complementa la IA... no te va a quedar Sandro.»

CLASE → M4C3

LoRA: el add-on

concepto

No es un modelo de generación por sí solo: es un agregado chico entrenado sobre el modelo base que incorpora o refuerza un concepto que el base no tiene (una cara, un estilo, lo que la empresa 'no quiere que veas'). Se conecta ANTES del K-Sampler: modelo y CLIP pasan por él.

«No es un modelo de generación por sí solo... es como una especie de add-on al modelo principal.»

CLASE → M4C2

Usar LoRAs (y combinarlos)

receta

Trigger word: la palabra clave del LoRA se pone en el prompt 'para no pisar lo que ya sabe el modelo'. Weight típico 0.8–1.5 — 'si yo lo pongo en 5, esto revienta la imagen de una'. En Z-Image NO se refuerza con paréntesis como en Stable Diffusion. Para combinar: encadenar dos nodos LoRA, o el Power Lora Loader (multi-slot con switches). Los LoRAs 'slider' funcionan como un dimmer (ej. film grain), no como un concepto.

HALLAZGO → En Z-Image/DiT la identidad vive en el transformer: aplicar el LoRA model-only (sin CLIP) alcanza — es lo que hace nuestro modo Colab.

Control de calidad de LoRAs

advertencia

receta

ControlNet: condicionar la composición

receta

NO es img2img: no le pasás la imagen para variarla, le pasás su ESTRUCTURA (bordes, profundidad, pose) para que la respete mientras el prompt pone el resto. Cadena: imagen de referencia → preprocesador → Apply ControlNet (con strength) → al conditioning. Exige coherencia: prompt de astronauta sobre mapa de guitarrista da un absurdo (ejemplo real de clase). El aspect ratio de la referencia debe aproximarse al de salida. Un mapa ya calculado se puede reusar sin recalcular.

«Le dice: che, quiero que respetés los rebordes de la imagen.»

CLASE → M4C3

El zoo de preprocesadores

herramienta

Cada uno extrae una estructura distinta de la imagen de referencia. Patrón de clase: versión estándar (solo Resolution) + nodo opcional de parámetros finos; el strength general va al final del grupo.

Depth Anything v2 Mapa de profundidad — 'el que mejor funciona' según clase.
Midas Depth Profundidad con más control: threshold, strength, resolution.
Canny Bordes por umbral alto/bajo (más/menos líneas). Existe versión propia de Z-Image.
DWPose Pose CON manos y cara (toggles cuerpo/manos/cara). Resolution >768, nunca 4K.
OpenPose Esqueleto básico — sin manos ni pies detallados.
Lineart / Scribble / DensePose / AnimalPose Líneas tipo manga, garabato, postura densa, postura animal.

Qwen VLM: la máquina de prompts

herramienta

Un modelo de visión+lenguaje adentro del grafo: le das una imagen y te escribe el prompt — o se lo conectás directo al CLIP (modo automático; ahí no te deja escribir a mano). Se le habla como a un chat: system prompt (rol) + user prompt (orden). Usos vistos en clase: describir para regenerar, inyectar el trigger de un LoRA al inicio, editar por lenguaje ('place it in Buenos Aires'), combinar dos imágenes, reestilizar, describir una singularidad facial para acercarse a alguien SIN LoRA, y armar prompts negativos. Toggle Unload All Models=True para estabilidad en la T4.

«Una máquina consistente de armar prompts les da consistencia en todos los casos, mucho más que un Lora, y pueden llevarlos mucho más lejos que un Lora.»

CLASE → M4C4

PLUS → El grupo QwenVL del workflow de la diplo incluye además un Master Prompt Loader con presets de estilo (Ghibli, soviet poster, claymation...), presets de cámara (Sony A1, Hasselblad...) y toggles (iluminación, profundidad de campo, watermark). Va conectado al user prompt, no al system.

Escalar: píxeles vs. detalle

receta

Un upscaler clásico (los .pth de OpenModelDB: 2x anime, 4x foto, restaurar JPG, caras) interpola píxeles. El Tile hace otra cosa: multiplica el tamaño, corta la imagen en cuadraditos y REPROMPTEA cada uno agregando detalle real (textura, poros). La perilla vuelve a ser el denoise: ~0.20 restaura fiel, 0.45–0.50 modifica bastante, cerca de 1 inventa y se notan los cortes entre tiles. El workflow 'Solo Tile' de la diplo escala cualquier foto — incluso vieja o rota — sin pasar por generación.

«Lo que nosotros estamos haciendo acá no es agregar píxeles, sino que es agregar detalles: es repromptear un cacho de la imagen.»

N4

Video: frames que se suceden

Primero sin modelo de video (forzando el motor de imagen), después con uno de verdad (LTX-2).

Un video es una sucesión de frames

concepto

La idea que abre todo: alimentá el workflow de imagen con un video y el K-Sampler procesa cada frame como una imagen más.

«¿Qué es un video? Una sucesión de frames... el K-sampler solo se da cuenta que está trabajando no en una imagen sino en un montón de imágenes.»

CLASE → M4C5

VHS: entrar y salir del video

herramienta

El pack Video Helper Suite. Load Video: force_rate (bajar 24→16 fps ahorra GPU), frame_load_cap (cuántos frames procesar: 0=todos, 1=solo el primero para previsualizar barato), format según el modelo destino. Video Combine: frame_rate, formato (MP4 H.264/H.265, GIF), y save_metadata — que embebe el workflow entero en el archivo: arrastrás ese video a ComfyUI y se reconstruye el grafo.

El problema de la consistencia

receta

Seed 1, 2, 3, 4 NO da un video: cada seed es un mundo. La receta que funcionó en clase (la 'idea pilla' de un alumno): img2img sobre cada frame + ControlNet de profundidad + denoise BAJO. Bajarlo acerca al video original (0.45 → 0.14 en vivo); subirlo da cosas más locas pero menos consistentes. El denoise es, otra vez, la perilla.

Interpolación: inventar frames intermedios

receta

No genera contenido nuevo: calcula los frames del medio (16→32/60/120 fps) para fluidez o cámara lenta. Modelo FILM (o RIFE) vía el pack ComfyUI-Frame-Interpolation, con su multiplicador ×2/×4. Va entre el VAE Decode y el Video Combine.

HALLAZGO → El 'interpolador de video.json' de la carpeta Modulo 4 es exactamente ese grafo mínimo: VHS Load Video → FILM VFI → VHS Video Combine. Tres nodos.

Modulo 4/interpolador de video.json

Escalar video

receta

El modelo de upscale se aplica frame por frame (primero interpolar, después escalar). Para detalle generativo en video existe SeedVR2 (detailer con su propia variante Tile — buscarlo en el Manager). La alternativa paga es Topaz; esto es gratis y abierto.

LTX-2: un modelo de video de verdad

herramienta

El preferido de la cátedra: init frame + end frame + prompt para el medio, o un video-guía. Resolución base ~720×512 (no hace 1080 exacto). Usa dos CLIPs y trae los 'sigmas' (el scheduling fino) ya calibrados por la comunidad — no calcularlos a mano. En el workflow viene todo agrupado en un subgraph (VAE de video + VAE de audio: genera imagen Y sonido).

HALLAZGO → El 'ltx2_3_imagen_a_video.json' staged en Modulo 4/ es ese workflow: LTXV + MultimodalGuider + audio VAE — listo para el día que el proyecto pida animar el archivo.

Easy Comfy: la síntesis

Nuestra capa sobre el mismo motor: todo lo anterior, condensado en controles — sin volverse caja negra.

Qué es

herramienta

comfyweb ('Easy Comfy'): una página web propia que arma por atrás el MISMO grafo de la cursada — Z-Image Turbo fp8 + encoder Qwen3-4B + VAE — y lo manda al ComfyUI de Colab por el túnel. Vos ves sliders y checkboxes; el grafo del nivel 2 sigue ahí abajo, intacto.

HALLAZGO → Verificado contra el código (2026-07-07): modo default 'diplocolab', con img2img real, stack de N LoRAs ('especiero'), calidad Turbo/Base/Mixta y refine encadenado.

herramientas/ComfyUI/.../comfyweb/server.js

No confundir con 'Easy Install'

advertencia

En clase el docente recomienda el 'Easy Install' de ComfyUI (el instalador .exe completo, con Manager) por sobre la versión Desktop/aplicación, que viene capada — hay packs de nodos que ni siquiera están en el Manager y piden git clone. Eso es un INSTALADOR. 'Easy Comfy' (comfyweb) es otra cosa: una capa de síntesis sobre un ComfyUI ya corriendo.

«En Confi son todas sonrisas... cuando tenemos que ir a buscar algo que necesitamos, ahí después se complica.»

CLASE → M4C4

Caja de vidrio, no caja negra

concepto

La diferencia con Midjourney no es la cantidad de botones: es que acá el 'modo fácil' es una puerta y no una pared. Cada control mapea a UN nodo con nombre y apellido (tabla abajo), el JSON del workflow se puede abrir en ComfyUI crudo, y cuando la UI te queda chica, pasás al grafo real sin cambiar de motor ni de modelo.

Qué esconde (a propósito)

concepto

Encoder fijo (Qwen3-4B/lumina2), VAE fijo, arquitectura y cables invisibles, LoRA siempre model-only en Colab, manejo de seed en el frontend. Está bien que el día 1 no toques nada de eso — la trampa sería que no PUDIERAS tocarlo nunca. La salida está documentada: abrir el JSON.

Límites actuales

advertencia

Sin inpainting ni outpainting. ControlNet e img2img son mutuamente excluyentes (subir imagen activa CN salvo que tildes img2img). El slider de strength CLIP del LoRA solo tiene efecto en el modo local completo. IPAdapter no existe para Z-Image (arquitectura demasiado nueva).

El arco completo

decisión

Empezá en Easy Comfy (resultado en minutos) → mirá el JSON que genera cada corrida → recreá ese grafo a mano en ComfyUI (nivel 2) → tocá lo que la UI no expone (nivel 3) → volvé a Easy Comfy cuando quieras velocidad. Ese ida y vuelta ES el bastón: la interfaz simple como punto de partida y de regreso, nunca como techo.

Los tres workflows de la cursada

DIPLO_imagen.json — el workflow madre de la cursada

43 nodos organizados en 5 grupos que se prenden y apagan según lo que la T4 aguante: 'generacion' (el núcleo del nivel 2), 'controlnet experimental', 'QwenVL' (la máquina de prompts), 'tiled upscale' y 'upscale sin tile'. Modelos: Z-Image Turbo GGUF Q5_K_M + encoder Qwen3-4B + VAE UltraFlux + ControlNet Union + un LoRA de ejemplo (LowPoly Papercraft) + upscaler AnimeSharp ×2. Los 5 grupos son, literalmente, el índice del módulo.

interpolador de video.json

El grafo mínimo de interpolación: VHS Load Video → FILM VFI → VHS Video Combine. Tomá un video ya generado y duplicale los frames.

ltx2_3_imagen_a_video.json

Imagen → video con audio: cadena LTXV completa (checkpoint, conditioning, guider multimodal, VAE de video + VAE de audio, scheduler con sigmas calibrados) rematada en Video Combine.

Cuando algo se rompe

Nodos en rojo al cargar un workflow

Manager → Install Missing Custom Nodes → Restart. Si el pack no está en el Manager (Scrumfy, SimpleQwen): git clone en custom_nodes + pip install -r requirements.txt — por eso no usar la versión Desktop capada.

M4C1 · M4C5

Texto rojo por todos lados en Colab

Solo importan los errores con botón rojo real. El resto es ruido de instalación (falsos negativos).

M4C1 · M4C2

'Model inference fail' / se cuelga a mitad de generación

Pico de RAM en la T4. Rutina: refrescar → si sigue, reiniciar la celda del túnel → 'reconnecting' → verde → refrescar.

M4C4

El LoRA no hace NADA

Revisar el nombre .safetensors letra por letra (un typo lo mata sin aviso), que el LoRA sea del modelo base correcto, y que el trigger word esté en el prompt.

M4C3

La descarga de Civitai falla para todos

Token compartido entre muchos usuarios. Generar API key propia y usar ?token=... en la URL.

M4C3

Subir mi imagen tarda una eternidad

Entrada demasiado grande (8000 px = horas). Redimensionar a ~1000 px antes de subir; hay nodo de resize por lado más largo.

M4C2

ControlNet recalcula el mapa en cada corrida

Colab gratis flushea la RAM entre generaciones para no perder la sesión. Se puede guardar el mapa generado y recargarlo como imagen para no recalcular.

M4C3

Cerré la pestaña y perdí todo

La VM se evapora. SIEMPRE: parar túnel → zip del output → descargar → verificar → recién ahí desconectar y eliminar el entorno.

Por abajo de la alfombra

Los pesos son tuyos (los bajás, los guardás, corren offline). El seed hace la salida reproducible. No hay capa de censura de marca decidiendo qué es representable — con la responsabilidad que eso transfiere. Y la infraestructura se alquila gratis por horas en vez de pagarse por abono. El sedentarismo cognitivo empieza cuando el modo fácil es una pared; acá es una puerta.
